## 如何更新这份副本

需要刷新到最新交易日时，**从源目录重新复制**（单向：源 → 副本，绝不反向写入）：

```bash
cd <仓库根目录>
SRC="数据/日度收益数据更新"
DST="商品趋势模型/历史数据"
cp -p "$SRC/期货主力前复权收盘价.csv" "$DST/"
cp -p "$SRC/日涨跌幅_填充.csv" "$DST/"
cp -p "$SRC/日涨跌幅_未填充.csv" "$DST/"
cp -p "$SRC/增量缓存/"*.csv "$DST/增量缓存/"
```
