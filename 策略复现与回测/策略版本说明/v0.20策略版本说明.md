# v0.20 策略版本说明

## 1. 文件定位

- 策略代码：`策略复现与回测/策略代码/资产风险平价策略0.20（剔除沪铝PTA）.py`
- 版本号：`0.20`
- 基础版本：`0.19`
- 主要目标：在 v0.19（IC替换IM + 日频调仓 + 日度胜率）的基础上，从风险平价商品资产池中删除 `沪铝主连`、`PTA主连` 两个品种，降低商品内部的集中度与极端回撤，并作为每日更新策略的生产版本。

## 2. 相对 v0.19 的核心变化

- 风险平价商品资产池从 5 个品种精简为 3 个：
  - 删除 `沪铝主连`、`PTA主连`。
  - 保留 `沪铜主连`、`原油主连`、`豆粕主连`。
- 股票（`红利低波ETF`）、债券（`10年国债主连`）、黄金（`沪金主连`）与股指期货（`沪深300主连 + 中证500主连`）资产池保持不变。
- 风险平价求解（EWMA 半协方差 + 凸优化 ERC）、日频调仓、保证金资金占用、闲置资金收益（GC001 方案）与换手成本逻辑完全延续 v0.19。
- 默认每日更新入口已切换为 v0.20 正式策略脚本；v0.19 与 `0.19_1（TL删除测试）` 保留为历史和测试版本。
- 回测指标中的胜率字段沿用 v0.19 的 `日度胜率` 口径，即 `日收益 > 0` 的交易日数量除以全部统计交易日数量；零收益日不算胜但计入分母。

## 3. 删除品种的逻辑

- `沪铝主连` 与 `PTA主连` 在样本期内波动大、夏普低、且多次出现深度回撤（PTA 全局最大回撤 −59.07%，沪铝 −30.63%），对组合风险预算的边际贡献不稳定。
- 二者与保留商品（沪铜、原油、豆粕）相关性有限，剔除后风险平价求解器的权重更集中于走势更平滑、回撤更可控的品种，组合波动与最大回撤显著下降，夏普反而提升。
- 该调整属于「品种取舍靠四象限框架逻辑，不靠样本内夏普最大化」的稳健性取舍，与留一法（jackknife）结论一致：删国债会明显恶化组合，加回铝/PTA 确会拉低夏普。

## 4. IC 数据与保证金口径

- `中证500主连` 交易收益使用 `数据/日度收益数据更新/日涨跌幅_未填充.csv` 中的真实 IC 期货收益。
- 权重估计使用 `数据/日度收益数据更新/日涨跌幅_填充.csv`；IC 上市前缺口使用中证1000指数日涨跌幅填充。
- IC 保证金沿用股指期货口径：
  - 交易所最低保证金：`8.00%`
  - 期货公司实际保证金：`14.00%`
- 策略默认使用期货公司实际保证金，即 `MARGIN_RATIOS = MARGIN_RATIOS_BROKER`。

## 5. 输出文件

运行 v0.20 正式策略（或每日更新入口）后生成以下标准回测输出：

- 每日净值：`策略复现与回测/回测指标/净值/策略每日净值走势_v0.20.csv`
- 年度及全局指标：`策略复现与回测/回测指标/指标/年度及全局回测指标_v0.20.csv`
- 日度仓位明细：`策略复现与回测/回测指标/仓位明细/策略日度仓位明细_v0.20.csv`
- 回测图表：`策略复现与回测/回测图表/回测图表_v0.20.png`

对应的「沪铝/PTA 删除测试」独立产物位于 `策略复现与回测/策略测试结果/AL和PTA删除测试_v0.20_1/`，测试代码为 `策略复现与回测/策略测试代码/资产风险平价策略0.20_1（AL和PTA删除测试）.py`。

年度及全局指标文件中的胜率列为 `日度胜率`。每日更新策略仍按日期分类输出日报、仓位、净值、指标、仓位明细和图表，不额外把版本号写入日报输出文件名。
