# v0.18 策略版本说明

## 1. 文件定位

- 策略代码：`策略复现与回测/策略代码/资产风险平价策略0.18（保证金修改+资金占用显示）.py`
- 版本号：`0.18`
- 基础版本：`0.16`
- 主要目标：在 `v0.16` 周频调仓和股指期货信号框架不变的基础上，调整品种保证金比例设置方式，并在回测指标与仓位明细中显示资金占用。

## 2. 相对 v0.16 的核心变化

- 将原单一 `MARGIN_RATIOS` 保证金参数拆分为两套参数：
  - `MARGIN_RATIOS_EXCHANGE_MIN`：交易所最低要求的保证金比例。
  - `MARGIN_RATIOS_BROKER`：期货公司实际保证金比例。
- 策略默认使用 `MARGIN_RATIOS_BROKER`，并通过 `MARGIN_RATIOS = MARGIN_RATIOS_BROKER` 保持原有资金占用计算逻辑不变。
- 年度及全局回测指标中，每一行组合/资产均输出 `平均资金占用`。
- 周度仓位明细中新增 `资金占用比例` 列，口径为调仓目标权重乘以默认保证金比例后的合计值。
- 除保证金比例与资金占用显示外，风险平价、周频调仓、股指期货信号和净值逻辑均延续 `v0.16`。

## 4. 收益与费用口径

- 交易日收益使用未填充交易收益数据。
- 调仓日扣除换手成本，费率为 `FEE_RATE = 0.0005`。
- 闲置资金收益基于交易收益数据中的 `一天期国债逆回购` 年化利率折算，并扣除 `REPO_FEE_RATE`。
- 保证金占用由默认 `MARGIN_RATIOS` 计算，即采用 `MARGIN_RATIOS_BROKER`。
- 单个资产的 `平均资金占用` 等于该资产在默认保证金比例表中的保证金比例。
- 策略组合的 `平均资金占用` 使用每日实际组合仓位乘以默认保证金比例后的日度序列均值。
