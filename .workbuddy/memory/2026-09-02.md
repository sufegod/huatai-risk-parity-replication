- **数据源可替换**（用户明确表示"数据库可以连其他家的，问题不大"）：
  - 脚本 `数据/日度收益数据更新/日度收益数据更新.py` 通过环境变量读取 JYDB 配置，切换点干净。
  - `.env` 仅需 4 个变量：`JYDB_SERVER` / `JYDB_DATABASE` / `JYDB_UID` / `JYDB_PWD`（+可选 `JYDB_DRIVER`，默认 `ODBC Driver 17 for SQL Server`）。
